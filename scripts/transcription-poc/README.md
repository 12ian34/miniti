# Local transcription POC (2026-10-09)

Offline comparison of on-device speech-to-text engines against Deepgram on the same audio, feeding the research in `docs/local-transcription-research.md`. Nothing in the app changed. Results and interpretation are in `RESULTS.md`; the raw tables are regenerated by `aggregate.py`.

## Engines

- Nemotron 3.5 ASR Streaming Multilingual 0.6B, Core ML int8, via FluidAudio 0.17.4 `StreamingNemotronMultilingualAsrManager` (the package Miniti already pins), 1120 ms and 560 ms chunk tiers, fed in chunk-sized blocks as a live session would.
- Apple SpeechTranscriber (macOS 26+; run here on macOS 27.0.1), file transcription with `audioTimeRange` attributes.
- Parakeet TDT 0.6B v3 via FluidAudio `AsrManager` (batch) and `SlidingWindowAsrManager(config: .streaming)` (live, 11 s windows), fed in 100 ms packets.
- Deepgram Nova-3 batch and live transcripts reused from `../diarization-poc/out` (the live dump used the app's exact query parameters).

## Data

- AMI meetings ES2004a and IS1009a (17.5 and 14 min, four speakers), headset mix and far-field array mic, 16 kHz mono, from `../diarization-poc/data`. Reference is every manual word from the AMI `words` XML merged in time order across the four speakers, fillers included. Overlapping speech makes absolute WER high for every system; compare engines against each other, not against model cards.
- FLEURS dev set, first 25 clips per language for en, es (Latin America), fr, de, nl, ru, pl, sv, el, streamed straight out of the Hugging Face tar archives by `fleurs_sample.py` (about 20 MB per language instead of the full archive).

## Run

```
python3 fleurs_sample.py sv_se,el_gr,pl_pl,nl_nl,ru_ru,de_de,es_419,fr_fr,en_us 25   # needs requests
curl -o ami/ami_public_manual_1.6.2.zip https://groups.inf.ed.ac.uk/ami/AMICorpusAnnotations/ami_public_manual_1.6.2.zip
(cd ami && unzip -o ami_public_manual_1.6.2.zip 'words/ES2004a*' 'words/IS1009a*') && python3 ami_ref.py
(cd harness && swift build -c release)      # downloads FluidAudio 0.17.4
./run_all.sh                                 # downloads the Core ML models on first use (about 2 GB total)
./harness/.build/release/harness paced nemotron ../diarization-poc/data/clip60.16k.wav 1120   # real-time paced cadence check
./harness/.build/release/harness paced parakeetlive ../diarization-poc/data/clip60.16k.wav
python3 aggregate.py > results-tables.md
```

`harness` modes: `nemotron <lang> <chunkMs> <out.json> <wav...>`, `apple <locale> <out.json> <wav...>`, `parakeet <out.json> <wav...>`, `parakeetlive <out.json> <wav...>`, `paced <nemotron|parakeetlive> <wav> [chunkMs]`.

`score.py` is a plain Levenshtein WER with a Whisper-style normaliser (lowercase, punctuation stripped, apostrophes kept). `ami/`, `fleurs/`, `out/`, and the harness build are gitignored.
