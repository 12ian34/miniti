# UI states

The top-level gates and primary screens for each platform. For UI patterns (focus rings, keyboard handling, etc.) see [patterns.md](patterns.md).

## macOS

- **Force update** (when server `min_version` > app version): Non-dismissable blocking screen (`ForceUpdateView`, shared with iOS). Shows "update required" message with download link. Takes priority over all other gates (terms, onboarding). Triggered by `checkForUpdates()` on launch; controlled server-side by bumping `MACOS_MIN_VERSION` / `IOS_MIN_VERSION`.
- **Deepgram and OpenAI permission** (first launch, or after a disclosure change): names both companies, says what each receives, offers "allow" and "not now". Not now opens the app with recording and AI features off and nothing sent; tapping record shows the same screen as a sheet; Settings, Privacy shows the choice and changes it. Backed by versioned storage in `@AppStorage` (`acceptedTermsVersion`, `declinedTermsVersion`, legacy bool migration).
- **Onboarding** (first launch, after terms): Responsive two-step flow. Miniti Free is the primary path, BYOK is secondary, then a real microphone meter lets the user verify permission and input before continuing or deferring setup.
- **Home** (`ReadyStateView`): Mode-aware — managed shows usage status, BYOK shows API pills; animated "multi-dimensional meetings" tagline; audio source panel and a concise capture-source/language summary; cog button (top-right) opens settings. The primary Start meeting action always begins a fresh unscheduled meeting. The upcoming list shows the next five connected-calendar events across coming days; selecting one opens a preparation sheet where private notes can be added or edited before starting, and those notes seed the meeting's live notes. `CalendarNudgeCard` renders above the start button when Google Calendar isn't connected and the nudge hasn't been dismissed.
- **Home (limit reached)**: In managed mode when 500 min used — inline "switch to BYOK" prompt, start button disabled
- **Home (device disabled)**: In managed mode when admin has disabled the device — shows "account disabled" message, start button hidden
- **Starting**: Spinner with "starting..." text while waiting for managed mode key or audio setup — stays on home screen until recording begins
- **Recording**: TerminalHeader with red dot + timer, stop button, dual labeled waveforms (mic green, system blue), transcript, notes, live insights. A bounded local heuristic can surface a dismissible investigation suggestion without making an AI call; the user can explicitly run in-app OpenAI web research or a Mac codebase investigation, and a proper shared-style header button opens the same two-choice popover at any time. The result sheet leads with the answer, keeps web citations visible and clickable, lists code files actually reviewed, supports refresh, and cancels cleanly on dismissal. With default-on Smart meetings, an amber prompt can ask whether quiet means the meeting ended or whether to end and start an approaching calendar event; calendar prompts offer End & start next, Keep recording, and Remind in 2 min, while quiet prompts offer End meeting and Keep recording. On macOS every pending start/end/quiet/calendar choice also expands and raises the non-activating floating recording surface, and optional incisive-question/monologue/filler guidance uses that surface while Miniti is frontmost. Notification Center is the fallback when attention is in another app or the surface is disabled; the same decisions remain in the menu bar. On macOS, finalized and interim content share one native scrolling TextKit 2 document: users can select across speaker turns, finalized selections survive incremental tail updates, and the view avoids the per-row SwiftUI selection overlays that could enter a multi-gigabyte layout loop during window resizing. Automatic follow-to-bottom is immediate rather than animated; actual user scrolling pauses follow and exposes Resume. iOS keeps lazy selectable speaker-turn rows and its existing Reduce-Motion-aware follow animation. Copy returns the complete transcript on both platforms, and saved transcript trimming retains a separate bounded native selection surface. The speaker legend wraps whole names onto additional rows when diarization finds more participants, rather than squeezing names into unreadable character columns. The history sidebar auto-collapses when recording begins and remains manually reopenable; at compact macOS widths the rail opens the full sidebar as an overlay drawer instead of expanding the split layout past the window edge. Coaching keeps multiple remote speakers compact as “Others”; its filler section can expand to show each named person's detail, while diarization IDs that resolve to the same name are merged first. Transcript and insight prose use the same size; Summary, Discussion, Actions, Questions, Coaching, Sales, Template, and Playbook content all follow that shared scale. Lowercase summary, questions, and coaching are persistent neutral tabs; Sales, Templates, and Playbook stay under More, and the More label shows the active template's short name (bant, spin, interview, check-in, stand-up, 1:1) while a template is selected. The Template view opens with a one-line caption naming the template, then its filled sections in template order; before the first fill it shows the same listening empty state as Sales. Category colors remain inside insight content rather than the tab chrome.
- **Stopped session**: Same layout; the app exposes brief transcript finalization as non-interactive progress, then generates final AI insights as meeting-scoped background work. Once that background phase starts, Back to meetings returns home immediately so another meeting can begin while the saved meeting continues updating in History. Resume remains unavailable until that meeting's background insights finish, preventing an older response from racing a resumed transcript. Actionable capture/service errors offer Retry or Resume instead of relying on logs.
- **Private mode (macOS, 2.12.0)**: while on, the Home session card reads "recording, private", the floating recording panel shows a lock, the insights pane shows a short private-mode note in place of Summary and Questions (Coaching still renders), and the More tab, investigate, catch-up and saved-meeting update controls are hidden. A start in Greek, Polish or Swedish is refused with a message naming the language.
- **History and Coaching**: Sidebar history opens saved-meeting detail with lowercase summary / questions / coaching as stable insight views plus, unless private mode is on, a More menu that remembers the specialist view picked for the meeting (one click returns to it, the indicator opens the menu) and lists, flat, Sales (MEDDPICC) with the built-in and custom templates, then Playbook (Docs), then manage templates and Insight settings links; items show names only. Sidebar navigation selection remains neutral. A deliberate two-finger trackpad swipe right/left moves backward/forward through visited Home, Coaching, and meeting destinations; a neutral edge dial follows available directions and fills at the release threshold. Vertical scrolling, sheets, momentum, and ordinary active text editing do not trigger navigation; the meeting-search field is the sole editing exception and loses focus automatically when navigation commits. The Coaching overview uses lowercase focus / stats / history tabs to separate personalized guidance and trends, overall/recent/latest comparisons, and the sortable meeting table. Its locally derived rows are prewarmed and retained above the destination view, so repeat visits show the previous result immediately; completed-meeting, transcript, speaker, title, language, or filler-word changes refresh only the affected meetings in the background while cached content remains visible, and deleted meetings are pruned immediately. Its focus view turns saved metrics into an offline, personalized next-meeting focus, strengths, recent-versus-previous trends, and a practical tip for fillers, pace, clarity, questions, talk ratio, and monologue length. Trend sections use one restrained 720pt-maximum reading column and enlarged desktop typography; they sit directly on the page background with fading metric-accent dividers, while only grounded transcript examples retain content-sized inset cards. Each metric keeps the same dedicated non-CTA color across live insights, saved detail, overview tables, and trend sections. Suggestions are emphasized as the primary takeaway and precede short, locally extracted transcript examples labelled with their source meeting title and date (never time); selecting an example opens that meeting. Questions are normalized by meeting duration and context-sensitive metrics are framed as broad coaching ranges rather than scores. Every Coaching overview row opens that meeting; a visible Coaching back action returns to the overview. Selecting Sales enables its future analysis; picking a template on a saved meeting fills it straight away; configuring a Docs MCP enables Playbook. Meetings are grouped into Pinned / Today / Yesterday / This week / Older and can be pinned from the row. A compact progress label marks saved meetings whose final insights are still being generated. Imported meetings show their source in both the list and detail metadata. macOS uses split panes (transcript + notes on left, insights on right); live and saved notes share the same drag interaction and retain at least 200pt for the transcript as the window shrinks. Saved trim-enabled transcripts use one bounded native text surface, so their scroll height matches rendered content while retaining cross-segment selection and precise deletion mapping. The detail header moves metadata/actions below the title at compact widths, then shortens the timestamp and uses accessible icon-only actions with tooltips at the narrowest supported width. Attio and Twenty use the shared CRM send sheet with semantic controls, a compact search field, neutral provider-specific scope tabs, collapsible payload details, and a fixed primary send footer that remains visible while results scroll. When task creation is enabled, the sheet scrolls to a complete checklist showing each task's deadline, assignee policy, and linked record; unchecked tasks are excluded while all action items remain in the meeting note. The main window is freely resizable down to its functional minimum and persists sidebar/history/insights collapse choices. Clicking the Dock icon explicitly deminiaturizes and foregrounds the existing main window.
- **Settings**: A resizable sidebar/detail window uses a fixed 230pt sidebar with no collapse button. The sidebar lists five groups, Setup (General, Account), Meetings (Recording, Transcription, AI, Templates, Notifications), Connections (Calendar, CRM, Webhooks, Playbook, Data), Privacy, and Support (About), one word per tab; Deepgram or This Mac is a segmented picker under Transcription, speaker names are an Off / GPT / Jev picker under AI, and private mode is the first row of Privacy. Sidebar search and `Command-F` return individual settings with breadcrumbs and scroll directly to the selected control; the last destination persists. Notifications explains the surface-aware delivery contract for opt-in live guidance and Smart-meeting decisions; Calendar & Meetings contains Smart meetings beside the independent Google Calendar controls and remains available without a connection. Every non-key destination works in Managed and BYOK modes. Opened via the cog button (`@Environment(\.openSettings)`), `Command-,`, or menu bar.

## iOS

- **Force update**: Same as macOS (shared `ForceUpdateView`)
- **Deepgram and OpenAI permission**: same as macOS (shared `TermsAcceptanceView`), without the private mode line
- **Onboarding** (first launch, after terms): Same as macOS (shared `OnboardingView`)
- **Home** (`ReadyStateView_iOS`): Native toolbar: test mic (leading), usage status (principal), settings gear (trailing). Mic waveform appears inline below nav bar when testing. The primary Start meeting action always begins a fresh unscheduled meeting. The upcoming list shows the next five connected-calendar events across coming days; selecting one opens a preparation sheet where private notes can be added or edited before starting, and those notes seed the meeting's live notes. The language picker remains below the action without repeating a `microphone • language` summary. `CalendarNudgeCard_iOS` renders when Google Calendar isn't connected and the nudge hasn't been dismissed. Mic-only (no system audio toggle).
- **Home (limit reached)**: In managed mode when free cap is reached — shows in-app "Upgrade to Pro — $4.99/month", "Restore Purchases", and BYOK fallback
- **Starting**: Spinner with "starting..." text while waiting for managed mode key or audio setup
- **Recording**: Native toolbar: home (leading), red dot + timer + waveform (principal), share (trailing). The same Smart meetings quiet/calendar prompt appears above the active content and can safely end or transition the recording without disturbing Live Activity/background capture. A bounded local heuristic can surface a dismissible investigation suggestion without making an AI call; the bottom bar's explicit Investigate action runs OpenAI web research inside Miniti and presents a selectable answer with clickable citations. Lowercase transcript / insights / notes and summary / questions / coaching use shared neutral tab strips; every selected surface and hit target fills its equal divided segment, including More. Sales, Templates, and Playbook stay under More; the More segment shows the active template's short name while a template is selected. The bottom bar also retains the labelled neutral `catch me up` control and red Stop action.
- **Stopped session**: Same layout with a saved/finalizing review card. Transcript finalization is non-interactive; once meeting-scoped background insights begin, the third bottom action becomes Meetings so the user can return home and start another recording. It becomes Done after insights finish. Resume of that same meeting stays unavailable while its background response is outstanding.
- **History tab**: `NavigationStack` list grouped into Pinned / Today / Yesterday / This week / Older, with leading swipe/context pinning and swipe-to-delete. A compact progress label marks saved meetings whose final insights are still being generated. Drill-down detail keeps lowercase transcript / insights / notes; insights keeps lowercase summary / questions / coaching visible as neutral tabs, with Sales / Templates / Playbook and direct Playbook setup under More; picking a template fills it immediately. Coaching metrics are computed from saved segments; multiple remote speakers appear as a compact “Others” summary whose filler section can expand into named per-person detail. Notes are editable.
- **Settings**: Accessible via the Home gear (no dedicated tab). iPhone retains searchable push navigation; search returns individual settings with breadcrumbs and scrolls to the selected control. Regular-width iPad uses a searchable sidebar/detail layout. Language and AI & Models are separate, as are Calendar & Meetings, Webhooks, and Docs MCP; the macOS-only CRM destination is omitted. Calendar & Meetings contains Smart meetings beside the independent calendar controls and remains available without a connection. Account & Plan retains StoreKit purchase/restore and BYOK keys; all non-key destinations work in Managed and BYOK modes. Since 2.12.0 the iOS list uses the same five groups and single-word tabs as macOS; Transcription holds the Speakers picker and language, AI the speaker-names picker, Privacy only diagnostics plus a note that private mode is on the Mac, About the links.
- **Coaching tab**: Uses the same lowercase focus / stats / history sections as macOS. Focus contains the one-column offline personalized focus, strengths, period-over-period trend cards, metric-specific tips, and clickable source-meeting transcript examples; those examples use a chevron-free accent hover state, keep the label and quote tightly grouped at left, and right-align the meeting title above its date. Stats contains an uninterrupted aggregate-comparison table with one-line label-side units, visible explanations below each metric, and semantically positive, negative, or neutral arrows. Six separate metric charts sit directly below the table. Each keeps its own value scale, visible numeric y-axis, and adaptive meeting-number x-axis from a handful to hundreds of meetings. History contains the meeting table. iPhone retains its accessible compact type scale while content-sized cards, untruncated copy, chart-specific VoiceOver summaries, and meeting-title-plus-date metadata keep the narrow layout readable. Talk ratio is omitted until another speaker is present, questions are normalized to a 30-minute meeting, and fewer than four eligible meetings are explicitly shown as a baseline rather than a trend.
- **Navigation**: iPhone uses the Record / Coaching / History bottom tab bar. Regular-width iPad uses an adaptive sidebar (native adaptable tabs on iOS 18+, explicit split navigation on iOS 17). Coaching rows push the saved meeting onto a navigation stack with a labelled Coaching back action.
- **Live Activity**: Shows timer, state, meeting title, and—when enabled—the latest transcript line. Tapping the Lock Screen or Dynamic Island activity returns to the active Record tab.
